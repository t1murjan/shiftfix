# shiftfix

Двойной Shift исправляет раскладку — как Caramba Switcher, только для Linux и без автопереключения.

```
Написали «ghbdtn» вместо «привет»?
Shift Shift → «привет», и раскладка уже русская.
```

- **Последнее слово:** `ghbdtn` ⇧⇧ → `привет`. Ещё раз ⇧⇧ — обратно; при трёх раскладках — по кругу.
- **Выделенный текст:** выделите `Ghbdtn vbh` и нажмите ⇧⇧ → `Привет мир`.
- Работает в Wayland и X11, с любыми раскладками и вариантами (украинская, Dvorak, «фонетическая»), с несколькими клавиатурами, включая Bluetooth.
- Окно настроек с темами оформления, значок в трее, служба systemd.

Написан на Rust. Две программы:

- `shiftfix` — служба: слушает клавиатуры и исправляет слова, показывает значок в трее.
- `shiftfix-gui` — окно: состояние, устройства, настройки, инструкция и журнал.

## Где работает

| Окружение | Переключение раскладки | Выделение |
|---|---|---|
| KDE Plasma (Wayland) | DBus KWin | wl-clipboard |
| Hyprland (в том числе Omarchy) | `hyprctl switchxkblayout` | wl-clipboard |
| Sway | `swaymsg` | wl-clipboard |
| GNOME (Wayland) | источники ввода GNOME (gsettings, Super+Space) | XWayland + xclip |
| X11 (любой оконный менеджер) | группа XKB | xclip |
| Остальное | ваше сочетание клавиш | — |

Проверялось в CachyOS (KDE Plasma, Wayland) и Omarchy (Hyprland).

В Sway задавайте раскладки для всех клавиатур: `input type:keyboard { xkb_layout us,ru }`. Слово перенабирается через виртуальную клавиатуру shiftfix, и без этих раскладок она напечатает его в своей.

## Установка

```sh
git clone https://github.com/t1murjan/shiftfix.git
cd shiftfix
./install.sh
```

Запускайте от своего пользователя, **без sudo** — пароль скрипт спросит сам, и только если что-то нужно поставить в систему. Он:

1. ставит недостающие пакеты (Arch/CachyOS/Manjaro, Debian/Ubuntu/Mint, Fedora, openSUSE) и при необходимости свежий Rust через rustup;
2. собирает обе программы и кладёт их в `~/.local/bin`;
3. даёт группе `input` доступ к `/dev/uinput` и добавляет вас в эту группу;
4. ставит службу systemd (без systemd — автозапуск сеанса) и ярлык «shiftfix» в меню.

Если вас только что добавили в группу `input`, **перезагрузитесь** — служба запустится сама. Затем откройте «shiftfix» в меню приложений.

Если установка оборвалась (ошибка, Ctrl+C), запустите `./install.sh` ещё раз — он доделает её.

В NixOS скрипт не подходит — он покажет, что добавить в `configuration.nix`. На Silverblue и других ostree-системах подскажет, какие пакеты доставить.

## Обновление

```sh
cd shiftfix
git pull
./install.sh
```

Тот же `install.sh` и ставит, и обновляет. Он пишет, что делает: «установка 0.4.0», «обновление 0.3.0 → 0.4.0» или «уже установлена 0.4.0», а перед установкой более старой версии спрашивает (без терминала нужен `--yes`).

- Сначала сборка: если она не удалась, установленная версия остаётся как была.
- Служба и окно останавливаются, программы заменяются, и служба запускается снова — если работала.
- Ваши настройки (`~/.config/shiftfix/config.toml`) не перезаписываются, выключенный автозапуск остаётся выключенным.
- При повторном запуске sudo обычно не нужен совсем.
- В конце — короткий итог: что обновлено, что осталось как было.

Раньше проект лежал в подпапке `shiftfix/` репозитория. Если вы ставили его оттуда, после `git pull` в этой подпапке останется старая сборка — её можно удалить: `rm -rf shiftfix/target`.

Версию показывают `shiftfix --version`, `shiftfix-gui --version` и блок «О программе» во вкладке «Инструкция».

## Удаление

```sh
cd shiftfix
./uninstall.sh            # программы, служба, ярлык, правило udev, вас — из группы input
./uninstall.sh --purge    # и ещё настройки и сборка
```

Скрипт сначала покажет, что нашёл, и спросит. Без `--purge` настройки остаются — поставите снова, и всё будет как было. Ещё параметры: `--yes` (не спрашивать), `--keep-group` (остаться в группе `input`), `--keep-build` (с `--purge` — оставить сборку). Пакеты (wl-clipboard, xclip и т. п.), Rust и сама группа `input` не удаляются: ими пользуются и другие программы.

## Окно shiftfix-gui

- **Главная** — состояние службы, переключатель «вкл/пауза», раскладки, поле, чтобы попробовать, последние исправления.
- **Устройства** — какие клавиатуры, мыши и тачпады слушаются. Если роль определилась неверно, её можно выбрать вручную.
- **Настройки** — интервал двойного нажатия, задержки, способ замены выделения, чем переключать раскладку, трей, автозапуск и **оформление**: светлая, тёмная или системная тема, палитры Breeze, Nord, Catppuccin и Gruvbox, свой акцентный цвет. Всё применяется сразу.
- **Инструкция** — как пользоваться, что делать, если не работает, и «О программе».
- **Журнал** — сообщения службы и кнопка «Проверить систему».

«Системная» тема берётся из XDG Desktop Portal и меняется вместе с системой; без портала тема тёмная. `shiftfix-gui --theme light|dark|system` меняет тему только на один запуск.

## Команды

| Что | Команда |
|---|---|
| Пауза / продолжить (удобно повесить на горячую клавишу) | `shiftfix --toggle` |
| Состояние | `shiftfix --status` |
| Проверить систему | `shiftfix --check` |
| Перечитать конфиг | `shiftfix --reload` |
| Юнит systemd / файл автозапуска для этого бинарника | `shiftfix --print-unit`, `shiftfix --print-autostart` |
| Журнал службы | `journalctl --user -u shiftfix -f` |

Если команды не находятся, добавьте `~/.local/bin` в `PATH`.

## Если не работает

- **Нет клавиатур или «нет доступа к /dev/input»** — вы ещё не в группе `input`: перезагрузитесь после установки.
- **«/dev/uinput недоступен»** — не применилось правило udev; перезагрузка помогает.
- **Что-то ещё** — `shiftfix --check` покажет, что не так с окружением, а вкладка «Журнал» — что делает служба.

## Ограничения

- Группа `input` даёт **любой** программе пользователя читать клавиатуру. shiftfix набранное не сохраняет: в памяти — только последние нажатия, в журнале — только длины слов.
- Выделенный текст исправляется в приложениях с PRIMARY-выделением (Qt/KDE, GTK, Firefox, Chromium); в терминале — нет.
- В IDE от JetBrains двойной Shift открывает Search Everywhere.
- Klipper запоминает вставленный текст в истории.
- keyd виртуальную клавиатуру shiftfix не перехватывает. Для kanata добавьте в `defcfg`: `linux-dev-names-exclude ("shiftfix virtual keyboard")`.
- fcitx5 и IBus как переключатели раскладки не поддерживаются.
