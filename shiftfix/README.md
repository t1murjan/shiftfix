# shiftfix

Двойной Shift исправляет раскладку — как в Caramba Switcher, только без автопереключения.

- **Последнее слово:** `ghbdtn` ⇧⇧ → `привет`. Ещё раз ⇧⇧ — обратно; при трёх раскладках — по кругу.
- **Выделенный текст:** `Ghbdtn vbh` ⇧⇧ → `Привет мир`.

Две программы:

- `shiftfix` — служба. Слушает клавиатуры и печатает исправления, показывает значок в трее.
- `shiftfix-gui` — окно с вкладками «Главная», «Устройства», «Настройки», «Инструкция» и «Журнал».

Где работает:

| Окружение | Раскладка | Выделение |
|---|---|---|
| KDE Plasma (Wayland) | DBus KWin | wl-clipboard |
| Hyprland | `hyprctl switchxkblayout` | wl-clipboard |
| Sway | `swaymsg` | wl-clipboard |
| GNOME (Wayland) | источники ввода GNOME (gsettings, Super+Space) | XWayland + xclip |
| X11 (любой WM) | группа XKB | xclip |
| Остальное | ваше сочетание клавиш | — |

В Sway задавайте раскладки для всех клавиатур: `input type:keyboard { xkb_layout us,ru }`. Слово перенабирается через виртуальную клавиатуру shiftfix, и без этих раскладок она напечатает его в своей.

## Установка

```sh
tar xf shiftfix.tar.gz && cd shiftfix && ./install.sh
```

Запускайте от своего пользователя, не через sudo. Скрипт ставит зависимости (Arch/CachyOS, Debian/Ubuntu, Fedora, openSUSE; на Silverblue и других ostree-системах подскажет, что доставить) и собирает обе программы. Если системный Rust старше 1.95, обновит его через rustup, если он есть, а если нет — предложит поставить. В NixOS скрипт не подходит: он покажет, что добавить в `configuration.nix`. Дальше он даёт группе `input` доступ к `/dev/uinput`, добавляет вас в эту группу и ставит службу systemd (без systemd — автозапуск сеанса). В меню появляется ярлык «shiftfix».

Если вас только что добавили в группу `input`, перезагрузитесь — служба запустится сама.

Удаление — `./uninstall.sh` в той же папке. Он остановит службу и окно и удалит всё, что поставил install.sh: программы, ярлык, значки, автозапуск, настройки, правило udev для `/dev/uinput`. Ещё он выведет вас из группы `input` и сотрёт сборку (`target/`). Сначала скрипт покажет, что нашёл, и спросит. Параметры: `--yes` (не спрашивать), `--keep-config`, `--keep-group`, `--keep-build`. Пакеты (wl-clipboard, xclip и т. п.) и Rust остаются: ими пользуются и другие программы. `./install.sh --uninstall` делает то же самое.

## Окно shiftfix-gui

- **Главная** — состояние службы и переключатель «вкл/пауза», раскладки, устройства, поле, чтобы попробовать, последние исправления.
- **Устройства** — что слушается и как понимается. Точка у устройства вспыхивает при нажатии или касании. Если роль определилась неверно, её можно выбрать вручную: клавиатура, мышь, тачпад, сенсорный экран, планшет/перо или «не слушать».
- **Настройки** — интервалы двойного нажатия, задержки, способ замены выделения, чем переключать раскладку, трей, автозапуск. Комментарии в `config.toml` сохраняются.
- **Инструкция** — как пользоваться и что делать, если не работает.
- **Журнал** — сообщения службы, кнопка «Проверить систему», перезапуск службы.

Тема окна — системная, светлая или тёмная (кнопки внизу боковой панели).

## Команды

| Что | Команда |
|---|---|
| Пауза / продолжить (можно повесить на горячую клавишу) | `shiftfix --toggle` |
| Состояние | `shiftfix --status` |
| Проверить систему | `shiftfix --check` |
| Перечитать конфиг | `shiftfix --reload` |
| Юнит systemd для этого бинарника | `shiftfix --print-unit` |
| Файл автозапуска для сеанса без systemd | `shiftfix --print-autostart` |
| Версия службы и окна | `shiftfix --version`, `shiftfix-gui --version` |
| Лог | `journalctl --user -u shiftfix -f` |

## Как устроено

- Каждое устройство читается в своём потоке (evdev), ввод не перехватывается. Роль устройства определяется по его свойствам:
  - касание сенсорного экрана или пера всегда считается кликом;
  - на тачпаде кликом считается только короткий тап;
  - «Video Bus», кнопка питания и датчики не открываются вовсе.
- В буфере хранятся **скан-коды** нажатых клавиш с Shift и раскладкой, в которой их нажали. Исправить слово — значит переключить раскладку, стереть N символов и нажать те же клавиши заново через собственную виртуальную клавиатуру `/dev/uinput`. Поэтому слово исправляется в любых раскладках.
- Буфер сбрасывается всем, что двигает курсор или уводит фокус: клик, касание, стрелки, Enter, Tab, Esc, сочетания с Ctrl/Alt/Meta, одиночный Alt/Meta, автоповтор.
- Выделение берётся из PRIMARY: на Wayland с data-control — `wl-paste --primary --watch`, в GNOME (через XWayland) и X11 — XFixes и xclip. Таблицы для перекодировки строятся из keymap, которую отдаёт композитор, поэтому подходят любые раскладки и варианты (украинская, Dvorak, «фонетическая»). Без keymap используются встроенные таблицы us/ru. Текст вставляется через буфер обмена, прежнее содержимое буфера возвращается (текст, картинка или скопированные файлы). Пароль из менеджера паролей (`x-kde-passwordManagerHint`) не возвращается — буфер очищается.
- Окружение определяется при первом обращении и заново, если оно сменилось. Адреса сеанса берутся из своего окружения, затем из окружения systemd user, затем ищутся живые сокеты Wayland, Hyprland, Sway и X11, так что служба работает, даже если стартовала раньше сеанса. Значок в трее появится, когда запустится панель.
- Пока сеанс неактивен по данным logind (вошёл другой пользователь, открыта текстовая консоль), исправления не выполняются.
- Клавиатуры, подключённые после входа (Bluetooth), подхватываются сами.
- GUI общается со службой через сокет `$XDG_RUNTIME_DIR/shiftfix.sock`.

## Ограничения

- Группа `input` даёт **любой** программе пользователя читать клавиатуру. shiftfix набранное не сохраняет: в памяти — последние нажатия, в журнале — только длины слов.
- Выделение работает в приложениях с PRIMARY (Qt/KDE, GTK, Firefox, Chromium). В терминале набор не заменяет выделение.
- В IDE от JetBrains двойной Shift открывает Search Everywhere.
- Klipper запоминает вставленный текст в истории.
- keyd виртуальную клавиатуру shiftfix не перехватывает (vendor 0x0FAC). Для kanata добавьте в `defcfg`: `linux-dev-names-exclude ("shiftfix virtual keyboard")`.
- fcitx5 и IBus как переключатели раскладки не поддерживаются.

Найденные при ревью ошибки и как они исправлены — в [BUGS.md](BUGS.md).

cargo test     # движок, таблицы (сверяются с настоящим xkb), устройства, бэкенды, буфер обмена, IPC, цикл службы
